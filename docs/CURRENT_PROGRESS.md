## 已完成流程

1. 发布人通过 AI 解析或手动表单创建活动，保存草稿并选择报名、签到、认定和企微群通知范围。
2. 活动依次经过学院审核老师、学院领导审批；驳回后可以修改并重新提交，审批记录完整保留。
3. 两级审批通过后由发布人正式发布，学生端可查看活动并按“先到先得”或“需要审核”模式报名。
4. 发布人可查看报名名单、审核报名、开启动态签到码、人工补签、统计出勤并导出电子或纸质签到表。
5. 正式发布后系统异步向已选择的企微群机器人发送活动通知，后台显示发送结果、失败原因并支持重试。

## 当前限制

- 本学院教师可以协作查看活动，但暂不支持由学院管理员代管或转交活动。
- 活动广场只展示完成两级审批并由发布人正式发布的活动，草稿和审批中的活动不会出现。
- 企微通知范围需要先配置目标群的机器人 Webhook；当前线上数据库尚未接入真实通知群。
- `campusactivityai.cn` 的 HTTPS 域名访问仍受备案状态影响，目前测试使用服务器 IP。
- 企业微信 OAuth 和公文链接抓取代码已完成，但真实启用仍需要学校提供企业配置、公文域名、访问权限和用户映射；学校统一身份认证协议尚待对接。
