# 校园活动平台完整功能测试报告

测试日期：2026-08-14

测试环境：本地前端 `http://127.0.0.1:5174/`，本地后端 `http://127.0.0.1:18080/`，H2 文件数据库

## 一、测试结论

本轮使用 4 组活动数据，分别覆盖先到先得报名、报名审核、驳回修改后二次审批、同学院协作草稿。登录权限、两级审批、报名与重报、现场签到、导出、通知失败隔离、数据持久化、移动端适配等核心流程均通过。

- 后端自动化测试：28/28 通过，0 失败，0 错误。
- 前端生产构建：通过。
- 服务重启后数据持久化：通过；活动 A、B、C 及其审批、报名记录仍存在。
- 页面运行检查：浏览器控制台无错误或警告。
- 核心权限检查：未登录访问返回 401，越权访问受保护接口返回 403。

## 五、外部配置相关说明

- 文本 AI 与图片 AI：本轮服务重启前配置状态正常。为避免产生外部接口费用，没有实际调用付费生图和解析接口。API 密钥只保存在后端内存中，重启后已按设计清空，需要在“AI 设置”中重新输入。
- 企业微信群通知：本轮使用本地占位群和占位 Webhook，验证了选择、保存和失败隔离；未向真实群聊发送消息。
- 公文通导入与企业微信 OAuth：本地环境未配置学校公文通和企业微信正式参数，因此未做真实外部联调。
- 纸质打印：已验证打印入口、表格排版与签名栏，未打开操作系统打印对话框。
